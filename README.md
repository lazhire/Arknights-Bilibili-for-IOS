# Arknights-Bilibili-for-IOS

明日方舟 v7.5 修补工具

!!!!!写在前面:
官方目前并未限制更改登录手段同时也没有提倡更改登录手段
砸壳ipa和自签名请自己想办法
本项目不承担账号损失


用法：完整解压，把一个砸壳 IPA 拖入根目录，双击“开始修补.bat”。
成功后在 output/ 生成带时间戳的未签名 IPA 和 report.json，再用 iLoader 签名安装。
需要 Python 3.11+。原包不覆盖；根目录零个或多个 IPA 时停止。

取消的限制：
- 不再要求来源于某个网站，不核对输入 IPA 的 SHA256 白名单。
- 不再核对输入宿主可执行文件的完整 SHA256。
- 允许容器压缩、ZIP 注释、签名数据等变化，只要下列结构检查仍通过。

仍有的适配边界：
- v7.5 对应明日方舟 2.7.81 / build 71、原 Bundle ID 和 app 目录结构。
- 检查所有可识别可执行文件的加密状态；不能仅改 cryptid 冒充砸壳。
- 保留宿主架构、构建 UUID、补丁位置的原始字节和 Mach-O 结构检查。
- 不匹配会停止，不能把任何版本的砸壳包都当成已适配。
- 既有桥接二进制没有修改，其运行时代码指纹保护仍然存在。
  打包成功仅表示静态步骤通过，不保证任意来源包可以启动或登录。

仍校验工具组件完整性、输出 ZIP CRC、写入内容和输出哈希；它们不是输入原包白名单。
check 命令只检查结构元数据；实际 patch 时才核对所有修改位置。
脚本不联网、不解密、不签名、不索要账号或证书。
预留约 4GB 输出空间，签名软件可能另需空间。
